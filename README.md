## Entry

The entry is a single emoji (1 to 8 characters), nothing else, standing in for the trip of my dreams. It lives in `entry.txt`.

## How to run

```sh
python3 main.py
```

`main.py` copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`).
